Pill-shaped primary action for Hello Park — use for any CTA; pair the chevron with "Learn more"-style links.

```jsx
<Button variant="primary">Visit park</Button>
<Button variant="ghost" chevron>Learn more</Button>
<Button variant="secondary">Contact</Button>
```

Variants: `primary` (orange, default), `secondary` (ink/dark), `ghost` (outline + orange wash on hover), `amber`.
Sizes: `sm` · `md` (default) · `lg`. Props: `chevron` appends "›", `disabled`. Always sentence-case labels.
