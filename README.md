# Hello Park — RFID-панель кассира и Анкета гостя

Репозиторий содержит прототипы веб-интерфейсов для сети мультимедийных парков **Hello Park**. Проект разделен на две основные части: панель кассира для управления RFID-браслетами и мобильная анкета гостя для саморегистрации посетителей.

## 🖥 Описание модулей

### 1. RFID-панель кассира (Корень проекта)
Веб-интерфейс для кассира парка. Разработан с использованием Tailwind CSS.
**Ключевой функционал:**
* Добавление аккаунтов родителей и детей с верификацией телефона по СМС.
* Быстрый поиск семей по ФИО или номеру телефона.
* Поочередная (пакетная) привязка физических RFID-браслетов к профилям детей сразу после регистрации.
* Проверка браслетов и мгновенный доступ к Аватару ребенка (игровой прогресс, уровни, баланс баллов).
* Выдача призов в зависимости от игрового уровня ребенка.
* Автоматическая фиксация истории посещений парка.

### 2. Мобильная анкета гостя (`/guest-registration`)
Мобильный веб-интерфейс для самостоятельного заполнения родителями при входе в парк.
**Ключевой функционал:**
* Ввод номера телефона и СМС-верификация.
* Ознакомление со всеми юридическими документами (правила парка, политика обработки персональных данных, правила лояльности).
* Указание ФИО родителя и добавление детей (имя, дата рождения).
* Генерация QR-кода карты лояльности для сканирования на кассе.

## 🧩 Основные сущности

* **Родитель (Взрослый):** Профиль в системе, содержащий ФИО и верифицированный номер телефона. Служит группирующим элементом для детей.
* **Ребенок:** Привязанный к родителю профиль с именем и датой рождения. К нему привязывается физический RFID-браслет.
* **RFID-браслет:** Физический браслет с UID-меткой. При сканировании привязывается к ребенку.
* **Аватар:** Виртуальный профиль ребенка в игровой зоне парка, содержащий игровой уровень, баланс Hello-плюсиков и статус.
* **Приз:** Награда (стикерпак, игрушка, билет и др.), статус которой зависит от уровня Аватара (Заблокирован / Доступен / Выдан).
* **Посещение:** Запись в истории, фиксирующая дату и время каждой привязки браслета к ребенку.

## 🚀 Инструкция по запуску

Для локального запуска и проверки работы интерфейсов потребуется установленный [Node.js](https://nodejs.org/).

1. Установите зависимости проекта (необходимы для работы Playwright в скриптах):
   ```bash
   npm install
   ```
2. Запустите локальный веб-сервер:
   ```bash
   npm start
   ```
3. Откройте интерфейсы в браузере:
   * **Панель кассира:** [http://127.0.0.1:3333/index.html](http://127.0.0.1:3333/index.html)
   * **Анкета гостя:** [http://127.0.0.1:3333/guest-registration/index.html](http://127.0.0.1:3333/guest-registration/index.html)

## ⚙️ Типичные команды и скрипты

Все вспомогательные скрипты вынесены в директорию `scripts/` и могут быть запущены через NPM или напрямую:

* **Запуск сервера:**
  ```bash
  npm start
  ```
* **Сборка ТЗ (из markdown в docx):**
  Скрипт компилирует `docs/ТЗ_Пакетная_привязка_браслетов.md` в `.docx` файл.
  ```bash
  npm run compile-docs
  ```
* **Сборка инструкции (из markdown в docx):**
  Скрипт компилирует `docs/Инструкция_Повторное_посещение.md` в `.docx` файл.
  ```bash
  npm run compile-returning-docs
  ```
* **Экспорт инструкции в PDF:**
  Рендерит HTML-файл интерактивной инструкции `docs/instruction.html` в PDF-формат `docs/Инструкция_Регистрация_и_Привязка.pdf` с помощью безголового браузера Playwright.
  ```bash
  npm run generate-pdf
  ```
* **Автоматические скриншоты:**
  Запускает Playwright для эмуляции интерфейса и создания актуальных снимков экрана в папку `docs/screenshots/`:
  ```bash
  node scripts/take_screenshots.mjs
  ```
